# 🏔️ RIDGE — Outdoor Gear & E-Commerce Storefront

A modern, responsive, and lightweight E-Commerce storefront UI built with pure **Vanilla JavaScript, HTML5, and CSS3**. Designed for high performance, smooth user interaction, dynamic filtering, sorting, and persistent shopping cart management.

## ✨ Features

* **🎨 Modern & Responsive UI:** Clean, minimalist dark/light mode responsive layout designed with CSS Custom Properties (Variables).
* **⚡ Dynamic Product Rendering:** Clean DOM manipulation using JavaScript without any external heavy frameworks.
* **🏷️ Category Filtering:** Quick filtering across multiple categories (*Jackets, Packs, Footwear, Accessories*).
* **📊 Dynamic Price Sorting:** Sort products seamlessly by price (*Low to High, High to Low, or Featured*).
* **🛒 Sliding Cart Drawer:** Interactive sliding cart drawer with real-time quantity updates and total calculation.
* **💾 Persistent Storage:** Integrated `localStorage` support to persist cart state across browser refreshes.
* **📱 Mobile-First Layout:** Optimized touch controls, mobile UI padding with CSS `env(safe-area-inset-*)`, and scalable grid design.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Flexbox & CSS Grid)
* **Scripting:** Modern JavaScript (ES6+)
* **State Management:** Browser `localStorage` API
* **Icons & Imagery:** High-resolution product showcase
